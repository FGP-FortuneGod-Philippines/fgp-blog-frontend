# FGP FortuneGod Philippines 

FortuneGod connects Asia-Pacific opportunities with the Philippine market driving innovation in trade, e-commerce, and sustainable growth

---

## About the Project

Founded in 2023 in Taoyuan, Taiwan, FortuneGod International Trade Co., Ltd. has quickly grown into a dynamic force in international trade, cross-border e-commerce, and strategic project investments.

Backed by over three decades of business presence in the Philippines, FortuneGod leverages deep local insights with global resources to introduce world-class products, advanced technology, and innovative services to the Philippine market. In 2025, the group established FGP FortuneGod Philippines Trading Inc. and launched ShoPilipinas.com, operated by ShoPilipinas E-Commerce Corporation, marking a milestone in building a next-generation O2O (online-to-offline) ecosystem.

## This website covers essential business needs, including:
- Homepage
- About the company
- Analytics Views
- It's People
- Chairman Information
- Company Announcements
- Philippine News

FGP helps businesses reach more clients, especially entrepreneurs and business professionals, while maintaining high-quality products and services.

## Getting Started
These instructions will get you a copy of the project running locally for development and testing purposes.

**Prerequisites**
- Node.js (v18 or higher)
- npm or yarn
- Docker (if using containerized setup)
- MySQL

## Installation
1. Clone the repository:
```
git clone https://github.com/FGP-FortuneGod-Philippines/fgp-blog-frontend.git
cd fgp-blog-frontend
```
2. Install dependencies:
```
npm install
```
3. Set up environment variables: Create a `.env` file in the root directory and add the following:
```
VITE_BASE_URL=
VITE_NEWS_API_KEY=
VITE_NEWS_PATH=
```
4. Run the development server:
```
npm run dev
```
5. (Optional) Start Docker containers if used:
```
docker compose up --build
```

## Usage
- Access the app at `http://localhost:3000`
- Use the backend API at `http://localhost:5000`
- Follow the endpoints in `/routes` to test functionality
- (Optional) Use `Postman` or `Insomnia` to test APIs
